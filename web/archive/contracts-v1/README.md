# The contract views, first version (archived 8 October 2026)

The Contracts tab as it was built on 8 October (PLT-4, the web UI). It had five pages, Binding, Sheet, Check, Sources and JSON, an entry card, and a rail listing every contract.

The engineer found it read like documentation of a gearbox housing. At 19:52 it was replaced by one product page (PLT-6): clean inputs, calculations with their methods pre-selected, pass criteria, and the design to beat.

These files are kept for reference. They sit outside `src/`, so they are not built and may drift from the current types. The views they drew are described in `docs/archive/2026-10-08-ui-views-v1.md`.
