# fastcae-sim

A design agent that generates verified cast gearbox housings from requirements:
- **Generation:** parametric CAD in FreeCAD.
- **Judging:** casting rules and FE on the GPU.
- **Benchmark:** the production GRC housing.

**Status:** planning. Development starts 6 October 2026.

**The plan:** [docs/plan.md](docs/plan.md).

**Data policy:** third-party part data (CAD, drawings, decks) and run outputs never enter git; see `.gitignore`.
