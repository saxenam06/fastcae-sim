# The first loop, start to end (PROTOTYPE)

**A prototype, not product code** (CLAUDE.md): nothing in `src/` imports it, and its outputs go to `data/first_loop/`, which git ignores. It is the LOP feature's work (`docs/features/loop/status.md`): one housing for the EV two-stage reducer taken from the completed contract through a plain shell and wall, its FE judgement, topology optimisation, ribs, and the FE judgement again, to learn which tools the product needs and where an agent's judgement belongs (the engineer, 9 October 01:54).

| Step | Script | What it makes |
|---|---|---|
| LOP-1 | `shell.py` | The plain housing: two halves split across the shafts, its walls round the gears' cavity (with a sump), the bearing bosses and seats, the seal bores, the split flange with its bolts, three mount bosses (A20) and the motor flange (A25); every face named by its role; STEP, the face names, the mass, pictures |

Run from the repository's root: `uv run python prototypes/first_loop/shell.py`.

The housing's own choices (its wall, bosses and flange) are the shell-and-wall tool's settings, in `shell.py`'s `SETTINGS`, each with where it comes from. The contract's values (the layout, the bearings, the clearances, the process) are read from the contract and the load tool, never typed here.
